01 — About

The short version

I'm a software engineer focused on building real-time, production-grade web applications with modern but pragmatic tools. I prefer shipping working features over perfect abstractions — every project I start has to solve an actual problem.

My current project, Student Hub, is a role-based academic platform built with Firebase, vanilla JavaScript, and zero build tooling. It handles authentication, real-time chat, file uploads, and an anti-cheat attendance system using rotating QR codes, GPS geofencing, and device fingerprinting.

I care about code that doesn't break, interfaces that don't feel like templates, and systems that hold up under real usage. If it's worth building, it's worth building properly.
